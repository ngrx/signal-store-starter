# NgRx Signals Demo Example

This directory contains example files demonstrating NgRx Signals patterns.

## Files

- `quiz.store.ts` - Example signal store implementation showing basic patterns
- `quiz.state.ts` - Example state definition for the quiz store

## Purpose

These files serve as educational examples of NgRx Signals best practices:

- Using `signalStore` with `withState`, `withComputed`, `withMethods`, `withHooks`
- Creating computed signals with `deepComputed`
- Managing state with `patchState`
- Implementing lifecycle hooks

## Note

These are demonstration files and are not part of the main application architecture.
The main application follows the architecture defined in `docs/prd-sup.md`.
